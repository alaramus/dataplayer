# الحسابات السحابية

الحساب السحابي هو الطريقة التي يصل بها الاتصال إلى السحابة نيابةً عنك: للحصول على رمز يسجّل الدخول إلى قاعدة بيانات، أو لقراءة كلمة مرور محفوظة في مخزن أسرار. وهو لك، كما هو مفتاح SSH: يذكره الاتصال، ومن تشاركه الاتصال يستخدمه دون أن يراه. تُحفظ الحسابات في **التفضيلات** ضمن **الحسابات السحابية**؛ وفي صفحة **الخيارات** من نافذة الاتصال زر **حساب جديد** أيضًا.

## الأنواع

- **Amazon Web Services**: **مفتاح وصول** و**المفتاح السري** الخاص به، مع **رمز الجلسة** لبيانات الاعتماد المؤقتة. ويمكنه تولّي **دور** — معرّف ARN الخاص به، و**المعرّف الخارجي**، واسم الجلسة ومدتها.
- **Google Cloud**: ملف **مفتاح حساب الخدمة** بصيغة JSON. ويمكنه التصرف بصفة حساب خدمة آخر إذا سمح له ذلك الحساب.
- **Microsoft Azure**: **كيان خدمة** — المستأجر ومعرّف العميل وسرّ العميل.
- **HashiCorp Vault**: **عنوانه**، ومساحة الأسماء وشهادة CA عند الحاجة، و**رمز** أو معرّف الدور والمعرّف السرّي لـ**AppRole**.

تُحفظ الأسرار مشفّرة ولا تُعرض مرة أخرى. يُجري **اختبار** أرخص استدعاء غير ضار يسمح به الحساب ويذكر من سجّل الدخول.

## هوية هذا الخادم نفسه

يمكن للحساب أيضًا أن يسجّل الدخول بصفة الجهاز الذي يعمل عليه DataPlayer: سلسلة بيانات الاعتماد الافتراضية في AWS، أو Application Default Credentials في Google، أو هوية مُدارة في Azure. يستطيع أي شخص استعارة هذه الهوية، لذا لا تُعرض إلا حيث يسمح التثبيت بذلك، وعندها لمستخدم خارق فقط.

## ما يفعله الاتصال بالحساب

يُصدر رمز لكل اتصال جديد ويُحفظ في الذاكرة فقط حتى قُبيل انتهاء صلاحيته؛ ولا يُخزَّن أي شيء يُصدر. تذكر صفحة كل مصدر أي طرق تسجيل الدخول فيه تأخذ حسابًا:

- PostgreSQL وMySQL: AWS IAM (RDS)، وGoogle Cloud IAM (Cloud SQL)، وMicrosoft Entra، ومخزن الأسرار، وبيانات اعتماد Vault الديناميكية.
- Redis: AWS IAM (ElastiCache، MemoryDB)، وMicrosoft Entra.
- MongoDB: AWS IAM (MONGODB-AWS)، ومخزن الأسرار.
- Kafka: AWS IAM (MSK).
- S3: حساب AWS بدلًا من مفتاح.

يسمّي **مخزن الأسرار** السرّ حيث يُحفظ: في AWS باسمه أو ARN الخاص به؛ وفي Google بصيغة `projects/P/secrets/S`، أو باسمه وحده في مشروع ملف المفتاح؛ وفي Azure بصيغة `VAULT/NAME`؛ وفي Vault بصيغة `MOUNT/PATH`. يُقرأ السرّ المكتوب بصيغة JSON بمفتاحَي `password` و`username` اللذين يمكن تغيير اسميهما؛ وأي سرّ آخر هو كلمة المرور نفسها.

الخادم الذي يتحقق من كلمات المرور عبر LDAP أو PAM أو RADIUS أو Active Directory لا يحتاج إلى حساب: فهي في نظر DataPlayer كلمة مرور.

## الحدود

- يحتفظ الحساب بنوعه؛ أنشئ حسابًا جديدًا لسحابة أخرى.
- لا يمكن حذف حساب يستخدمه اتصال؛ ويذكر الرفض تلك الاتصالات.
- الرمز الذي تنتهي صلاحيته أثناء نسخ احتياطي طويل لا يوقفه: يبقى الاتصال الذي فتحه صالحًا.
- لا تستطيع أدوات Kafka في الطرفية تسجيل الدخول عبر AWS IAM أو OIDC بعد.
