# Kubernetes

عنقود Kubernetes يُوصَل إليه عبر خادم الـ API الخاص به: أي عنقود — عنقودك أنت،
أو k3s، أو kind، أو عنقود تشغّله سحابة. ترى مساحات الأسماء فيه وكل نوع من
الكائنات التي يقدّمها، بما فيها المخصّصة، كجداول العنقود نفسه، وما يقوله العنقود
عن كل كائن، وسجلات الـ Pod، وتقارير العنقود. طريقة عمل الاتصالات عمومًا موضّحة في
صفحة [الاتصالات](connections.md).

## ما يمكنك رؤيته

- مساحات الأسماء وكل نوع من الكائنات فيها، مجمّعة كما في kubectl
- الأنواع خارج مساحات الأسماء: العقد ووحدات التخزين والفئات وغيرها
- الموارد المخصّصة، وتُكتشف كما تُكتشف الأنواع المدمجة
- كائنات النوع في جدول كما يطبعه `kubectl get`، مع الفرز والتصفية
- نظرة عامة على الكائن: حالته وبياناته الوصفية وحالاته ومحتواه
- الكائن بصيغة YAML أو كشجرة JSON
- أحداث الكائن والـ Pods التي يختارها حمل عمل أو خدمة
- سجلات الحاوية، الأحدث أولًا
- العنقود: الإصدار والعقد والـ Pods حسب المرحلة والأحداث وموارد الـ API

## الاتصال

**تسجيل الدخول باستخدام** يحدد كيف يسجّل DataPlayer الدخول إلى العنقود:

- **ملف kubeconfig**: الصق الملف، أو اقرأه من القرص بالزر المجاور للحقل. يجب أن
  تكون الشهادات والمفاتيح داخل الملف، لا أسماء ملفات؛ والأمر
  `kubectl config view --minify --flatten` يكتب ملفًا كهذا. **السياق** يحدد
  السياق المطلوب؛ وإن تُرك فارغًا فالسياق الحالي في الملف.
- **رمز**: عنوان `https://` لـ **خادم الـ API**، و**شهادة CA** الخاصة به، و**رمز**
  bearer، كرمز حساب خدمة مثلًا.
- **شهادة عميل**: خادم الـ API، والـ CA الخاصة به، و**شهادة عميل** و**مفتاح عميل**
  يقبلهما العنقود. يجب ألا يكون المفتاح مشفّرًا.

اترك **شهادة CA** فارغة فقط لخادم وقّعت شهادته جهة عامة. اترك **مساحة الأسماء**
فارغة لرؤية كل ما يُسمح لك بسرده؛ واذكر واحدة إن كان حسابك لا يعمل إلا فيها.

تُرفض بعض ملفات kubeconfig، ولكلٍّ سببه:

- التي تسجّل الدخول بتشغيل برنامج — `gke-gcloud-auth-plugin` و`aws`
  و`kubelogin` وأمثالها: DataPlayer لا يشغّل شيئًا على خادمه؛
- التي تذكر ملفات بدل أن تحوي بياناتها؛
- التي تُطفئ التحقق من شهادة الخادم؛
- التي تسجّل الدخول باسم مستخدم وكلمة مرور، وقد أزالت Kubernetes ذلك.

لا تختر **نفق SSH** إلا إذا كان خادم الـ API لا يُوصَل إليه إلا من شبكة أخرى. يجب
أن يعمل العنقود بـ Kubernetes 1.27 أو أحدث.

## الفهرس

- **العنقود** يضم تقارير العنقود، وهي موضّحة أدناه.
- **مساحات الأسماء** يسرد كل مساحة أسماء، وأولها **كل مساحات الأسماء** الذي يعرض
  كل نوع عبرها جميعًا مع عمود **Namespace**.
- داخل مساحة الأسماء تُجمَّع أنواعها: **أحمال العمل** و**الشبكة** و**الإعدادات**
  و**التخزين** و**أخرى**. تضم «أخرى» كل نوع يقدّمه العنقود ولا يكون من الأنواع
  المعروفة، ومنها الموارد المخصّصة، وكلٌّ باسم مجموعة الـ API الخاصة به.
- **موارد العنقود** يضم الأنواع خارج مساحات الأسماء، مجمّعة بالطريقة نفسها، مع
  **العنقود** للعقد ومساحات الأسماء والتعريفات.
- يُفتح النوع جدولًا أعمدته هي التي يعرضها له `kubectl get`، مع **Created** بدل
  العمر ليمكن الفرز. ويعرض كل كائن في الفهرس أعمدته الأولى بجانب اسمه، مثل
  `1/1 · Running`. ولا يُسرد أكثر من عشرة آلاف من النوع الواحد.

## كيف يُفتح الكائن

- انقر الكائن لفتح نظرته العامة: النوع ومساحة الأسماء والإنشاء والمالكون والحالة،
  ثم ما يُقرأ هذا النوع من أجله — عقدة الـ Pod وعناوينه وحاوياته مع صورها وحالاتها
  وعدد مرات إعادة تشغيلها؛ والنسخ المطلوبة والجاهزة والمحدَّثة لـ deployment؛
  ونوع الخدمة وعناوينها ومنافذها؛ وإصدارات العقدة وسعتها؛ وفئة مطالبة وحدة التخزين
  وحجمها — ثم حالاته وتسمياته وتعليقاته التوضيحية.
- يفتح رأس النظرة العامة الكائن **بصيغة YAML** أو **بصيغة JSON** في علامة تبويب
  مستقلة. وتُحذف الحقول التي تحفظ فيها Kubernetes من غيّر ماذا.
- تُفتح صفحاته جداولَ في علامات تبويب مستقلة: **الأحداث** عنه؛ والـ **Pods** التي
  يختارها deployment أو stateful set أو daemon set أو replica set أو job أو
  خدمة؛ و**السجلات** للـ Pod، صفحة لكل حاوية: الوقت والنص، الأحدث أولًا، حتى عشرة
  آلاف سطر، ويُقطع كل سطر عند 16 كيلوبايت.
- **لا تُعرض قيم الـ Secret أبدًا.** تسرد نظرته العامة مفاتيحه وأحجامها، ويضع
  YAML وJSON الخاصان به حجمًا مكان كل قيمة.

## قسم العنقود

- **نظرة عامة**: الإصدار والخادم والسياق ومن تكون في نظر العنقود والعقد الجاهزة
  والمنصّات وعدد مساحات الأسماء والـ Pods في كل مرحلة.
- **العقد**: حالة كل عقدة وأدوارها وإصداراتها وعنوانها ونظام تشغيلها وبيئة تشغيل
  الحاويات وسعتها وما يمكن تخصيصه وtaints الخاصة بها.
- **الأحداث**: ما سجّله العنقود مؤخرًا، الأحدث أولًا.
- **موارد الـ API**: كل نوع يقدّمه العنقود ومجموعته وإصداره ونطاقه وأفعاله.

## عندما يُرفض شيء

- خادم API لا يُوصَل إليه، أو شهادة غير موثوقة، أو رمز أو شهادة غير مقبولين، كلها
  توقف الاتصال كله، وتقول كل شاشة السبب.
- قد ترفض قواعد الوصول الخاصة بالعنقود طلبًا واحدًا. ويُقال ذلك بعبارة **لا يسمح
  العنقود لهذا الاتصال** مع ما طُلب، مثل `list secrets`؛ ويبقى باقي العنقود
  قابلًا للقراءة.

## ما لا يملكه Kubernetes هنا بعد

- تغيير الكائنات: التوسيع وإعادة التشغيل والحذف والتحرير بصيغة YAML
- تفريغ عقدة، وطرفية داخل الحاوية، وسجلات تواكب
- مقاييس على لوحة، والبحث، وفتح قاعدة بيانات في العنقود كاتصال
- تسجيل الدخول إلى Google Kubernetes Engine بحساب Google Cloud
