# Сервисы и терминалы

DataPlayer может запускать для вас серверы баз данных и другие источники на
машине, где он работает, и открывать терминалы к вашим подключениям. Оба живут в
панели внизу экрана, которая открывается своими инструментами на нижней левой
панели.

## Запуск сервера здесь

Если эта установка может запускать контейнеры, панель вида источника в
**Новое подключение** предлагает **Запустить … здесь** — PostgreSQL, MySQL, Redis, SSH-сервер
и другие. Как это спрашивается и что вы получаете, описано на странице
[Подключения](connections.md). Сервер работает в Docker на этой машине, а его
подключение создаётся для вас.

Кнопка, которая неактивна, при наведении объясняет почему: эта установка вообще не
может запускать контейнеры или не может запускать этот вид.

## Инструмент Services

**Сервисы** показывает серверы, запущенные здесь для вас, с состоянием каждого и
его контейнера.

- **Остановить** останавливает сервер; то, что в нём хранится, остаётся. **Запустить**
  запускает его снова.
- **Начать заново** удаляет сервер, который не запустился, вместе с его данными, и
  пробует снова.
- **Где он доступен** показывает хост, порт, пользователя и базу данных для
  подключения из ваших инструментов, а также строку подключения. Пароль показывается
  только один раз, при создании сервера, если только вы не ввели свой.
- **Что он вывел** показывает собственный вывод сервера.
- **Удалить сервис** удаляет сервер и всё, что в нём хранится.
  **Удалить и подключение** удаляет и его подключение.

Запуск, остановка и удаление выполняются в фоне; колокольчик активности показывает,
как они идут.

## Терминалы

**Терминалы** открывает терминал к одному из ваших подключений:

- для SSH-подключения — оболочку на этом сервере;
- для подключения к базе данных, которое это поддерживает, — её собственную клиентскую
  программу: `psql`, `mysql`, `cqlsh`, `zkCli`, инструменты Kafka, `rabbitmqadmin` и
  другие — вошедшую под этим подключением. Она работает в контейнере, который
  запускает этот сервер, поэтому предлагается только там, где контейнеры разрешены.
  На странице каждого вида источника написано, что он открывает.

Одновременно может быть открыто несколько терминалов, каждый на своей вкладке панели.
Терминал получает все клавиши только себе, включая Ctrl+K. Закрытие вкладки его
завершает.

Терминалы открываются только для подключений, которые вам принадлежат.

## Резервные копии

У базы данных, которую можно скопировать наружу, в меню действий каталога есть
**Резервные копии**: **Создать резервную копию** создаёт резервную копию — файл в вашем
собственном хранилище; **Восстановить** записывает её обратно, заменяя то, что там
есть; удаление убирает файл. На странице каждого вида источника написано, есть ли у
него резервные копии.

## Журнал

**Журнал** на нижней левой панели администратора читает собственный журнал сервера:
его можно фильтровать по уровню и процессу, искать по тексту, по ссылке из сообщения
об ошибке или по пути, и следить за ним по мере роста.
