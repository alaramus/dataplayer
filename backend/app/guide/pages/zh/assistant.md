# AI 代理

代理在左侧栏顶部切换开关的 **AI** 空间中回答问题。它像你一样通过连接工作：列出连接，查找并读取表和文件，运行查询和操作，在 Data 空间中打开内容，绘制图表，并阅读本指南以回答有关 DataPlayer 本身的问题。代理想要做的更改会先征求你的意见。

## 第一次聊天之前

代理使用你自己的模型提供商密钥，提供商包括 Anthropic、OpenAI、Google、DeepSeek 等。

1. 打开 AI 空间和 **设置**。
2. 选择一个模型。旁边的钥匙图标会打开提供商的密钥设置：粘贴密钥，点按 **检查**，然后保存。同一个密钥可用于该提供商的所有模型。
3. 在设置中选择的模型，是新聊天默认使用的模型。每个聊天可在其自己的输入框中选择其他模型。

## 聊天

- 点按 **新建对话** 开始一个聊天。在 **向智能体发送消息** 中输入内容，然后点按 **发送**；如果浏览器支持语音输入，也可以用麦克风听写。
- 代理工作时，其步骤会逐一显示：读取了什么、运行了什么、耗时多久。**停止** 会结束回答。
- 回答为格式化文本，可包含表格、图表和示意图。每项都可以复制或朗读。
- 在回答中选中文字会出现 **添加到对话**（将文字引用到你的下一条消息中），以及 **更多详情**（请快速对话解释这些内容）。

## 代理了解的内容

代理看不到你的屏幕。要让它关注某些内容，请使用 **附加标签页或文件**：

- **工作区标签页……**：最多五个已打开的标签页——表、目录、查询或结果——用于下一条消息；
- **来自电脑的文件……**：文本文件，以及供能读取图像的模型使用的 PNG、JPEG、WebP 或 GIF 图像。

没有附件时，代理会通过搜索按名称查找内容。如果多个连接与某个名称匹配，它会询问你要哪一个。

## 更改

输入框中的 **更改** 用于设置代理在本聊天中可以进行的更改：

- **只读**：在本聊天中不做任何更改；
- **更改前询问**，每个聊天的初始设置：更改会在卡片上等待你的回应，卡片提供 **Allow once**、**Allow all changes in this chat** 和 **允许每个对话中的所有更改**。卡片会显示将要发生的更改——即语句，以及删除操作会连带删除的内容；
- **允许更改**：本聊天中的更改无需询问即可执行；
- **让 Jev 决定**：由 Jev（一项拥有自己密钥的独立服务）在每次更改前做出决定；
- **允许每个对话中的所有更改** 是你的设置，而非某个聊天的设置。可在 **设置** 的 **确认** 中再次关闭。

等待你回应的聊天会列在活动铃铛的 **需要你处理** 下。为控制台设置了 **只读** 的连接永远不会被写入，你没有的访问级别也永远不会被使用。

## 代理可以读取哪些连接

只有当连接的所有者在该连接的 **权限** 页面中开启 **允许向第三方发送数据** 时，代理才会读取该连接：所读取的内容会发送给模型提供商。否则，代理只能看到连接的名称和类型，其他内容一概不可见。所有者可以在被拒绝的步骤中允许此项；与你共享该连接的人会被告知应向所有者询问。

之后关闭此设置，会使已从该连接读取的内容不再用于该聊天的后续回答。

## 聊天、项目与归档

- 聊天列表顶部是 **已固定** 的置顶聊天，并可按名称筛选。
- 聊天可以置顶、移入项目、重命名和归档。
- **新建项目** 用于分组聊天。删除项目时，会询问其中的聊天是返回列表还是进入归档。
- 设置中的 **归档** 可以恢复已归档的聊天，或将其永久删除。

## 由 Jev 选择模型

**由 Jev 选择** 代替指定某个模型，让 Jev 在你已设置密钥的模型中为每个回答选择一个模型。你的请求会发送给 Jev 的提供商 TypeSafe，由其进行选择。这需要在设置中配置 Jev 密钥。

## 快速对话

左侧栏顶部的 **快速对话** 会打开一个窗口，用于在任何空间与模型进行普通对话。它没有工具，也无法读取 DataPlayer 中的任何内容。在台式机上的 Chrome 中，它可以由 Gemini Nano 回答；Chrome 下载完成后，Gemini Nano 在你自己的电脑上运行，因此内容不会离开你的设备。快速对话与代理的聊天记录出现在同一历史列表中。

## 外部 MCP 服务器的工具

代理还可以调用你添加的 MCP 服务器的工具：问题跟踪系统、维基、你自己的服务等。

1. 打开 AI 空间和 **设置**，然后在 **外部 MCP 服务器** 下点按 **添加服务器**。
2. 填写名称和 Streamable HTTP 地址，例如 `https://mcp.example.com/mcp`。**Bearer 令牌** 和 **其他请求头** 会随每个请求发送；保存后不会再次显示，留空的字段会保留已设置的值。
3. **工具** 会向服务器询问其提供的工具。每个工具会显示 **只读** 或 **先询问**，并可以关闭。

- 没有声明仅读取的工具会被视为更改：代理会在执行前询问，并显示它将发送的参数；**只读** 聊天会拒绝它，而 **允许更改** 则允许其运行。
- 输入框中的服务器图标可为该聊天开启或关闭各个服务器。
- 无响应的服务器会从该次回答中略去，聊天的其余部分照常进行。
- 此列表仅你自己可见。代理传给工具的内容会离开 DataPlayer，其中包括从你的连接中读取的数据。
- 指向本机或其私有网络的地址会被拒绝，除非安装设置允许。

## 外部 AI 代理

DataPlayer 之外的代理——Claude Code、Cursor、Codex 等——可以通过 DataPlayer 的 MCP 地址使用你的连接。

1. 从用户菜单打开 **偏好设置**，然后点按 **MCP 访问**。
2. **新建令牌**：填写名称，选择 **只读** 或 **完全访问**，并设置过期时间。**只读** 可读取目录、行和查询，并拒绝一切更改；**完全访问** 可以不经询问地更改数据和执行操作。
3. 复制令牌：它只显示一次。窗口还会给出用于配置所选客户端的命令行或文件条目。

外部代理拥有与本代理相同的工具（包括本指南），并且只能读取所有者允许向第三方发送数据的连接。**撤销此令牌** 会使其在下一次调用时失效。

## 限制

- 一次回答最多进行 50 次工具调用；超过时请提出范围更窄的问题。
- 一次读取最多返回 20 行。
- 一条消息所附文件的数量和大小都有限制；输入框会说明已达到哪项限制。
