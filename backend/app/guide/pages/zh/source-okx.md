# OKX

OKX 的公开市场数据：现货、USDT 与 USDC 期货以及反向期货，包括永续和交割。你可以查看每个交易对最近一天的行情和交易规则，以行的形式读取交易对的K线、最近三个月的成交和订单簿，并实时观看其市场。不会更改 OKX 上的任何内容，也不需要密钥。连接的一般用法见[连接](connections.md)页面。

## 你可以看到的内容

- 现货、USDT 与 USDC 期货、反向期货，交易对按计价资产分组
- 每个交易对最近 24 小时：价格、涨跌、最高、最低和成交量
- 每个交易对的交易规则：价格步长和数量步长
- 交易对任意周期的K线，从一秒到一个月
- 交易对最近三个月的成交，按编号或时间查找
- 交易对的订单簿，买单和卖单及累计数量
- 交易对的实时行情：图表、订单簿和成交在同一屏幕上
- 以上任何一项都可下载为文件
- OKX 的时钟、维护状态以及每项限额的使用情况
- 仪表板上的限额和 OKX 的响应
- 按名称或资产查找交易对
- 管道中交易对的成交或K线，每次运行只取新的
- 使用密钥时：余额、持仓、订单、我的成交、充值和提现

## 你可以更改的内容

- 无：市场数据只读

## 连接

窗口的**连接**页面要求选择**端点**：

- **OKX** — `www.okx.com`，其数据流在 `ws.okx.com`；
- **OKX Europe** — `eea.okx.com`，OKX 的欧洲服务：一个独立的市场，有自己的价格和成交；
- **模拟交易** — OKX 的模拟市场，有自己的价格。
- **OKX，使用 API 密钥**、**OKX Europe，使用 API 密钥**和**模拟交易，使用 API 密钥** —— 同上，并且还能读取密钥所属的账户。它们需要密钥、密钥的私钥以及创建密钥时设定的密码短语。

OKX 不为部分国家提供服务，包括美国。如果检查提示 OKX 不为此地址或地区提供服务，说明 DataPlayer 服务器位于其中之一；OKX Europe 只为欧洲经济区提供服务。

## 目录

- 首先是**交易所**：OKX 和此连接对自身的说明。
- **市场**：每个市场一个文件夹，列出其交易对。点击一行会直接打开其**行情**图表。
- **现货**、**USDT 与 USDC 期货**和**反向期货**。期货中同时包含 OKX 的永续合约和交割合约。每个市场包含**行情列表**、**交易对**，以及每种计价资产一个文件夹，交易对最多的排在最前。
- 计价资产下是其交易对，只包含当前正在交易的。永续合约以 `-SWAP` 结尾，例如 `BTC-USDT-SWAP`；交割合约以日期结尾，例如 `BTC-USDT-261225`。
- 交易对下有**行情**、按周期分系列的**K线**、**成交**和**订单簿**。

## 行情

**行情**是每个交易对的第一个节点，打开的标签页会随市场变化：顶部是当日数据，K线位于成交量之上，订单簿显示每档深度，成交实时出现。

- 在顶部选择K线周期；滚动或拖动图表可回看。
- 首次加载之后，所有数据都来自 OKX 的数据流，不占用它的限额。同一交易对的多个标签页共用这些数据流。
- 如果网络中断，标签页会提示并自动恢复。

## 表格

- **行情列表**：每个交易对一行，最活跃的在前。每一列都可排序和筛选。每十秒刷新一次。OKX 不提供 USDT 与 USDC 期货的计价成交量，所以那里没有这一列，最活跃的是以币计成交量最大的。
- **交易对**：每个交易对一行及其规则。期货另有 OKX 的类型——永续为 `SWAP`，交割为 `FUTURES`——交割合约的交割日期和上架时间。反向期货另有一张合约值多少 USD。
- **K线**：最新的在前；按 **open_time** 排序可从最早的开始，在其上筛选可选择读取的起止。尚未收盘的K线 `closed` 为 false。日线和周线在 UTC 午夜开盘。
- **成交**：最新的在前。OKX 为交易对的成交连续编号并保留三个月：在 **id** 或 **time** 上筛选可选择查看的位置，按 **id** 排序可从最早的开始。
- **订单簿**：先是买单从最优开始，再是卖单从最优开始。在 **level** 上筛选可选择深度，最多 400；默认 100 档。在 **side** 上筛选只看一边。
- **volume** 始终以基础资产计，**quote_volume** 以计价资产计。OKX 以合约张数计算期货；DataPlayer 将每项换算为其价值。反向期货的成交数量以 USD 计，所以那里的列名为 **quote_quantity**，订单簿的数量也以 USD 计。
- 价格和数量都是精确的小数，与 OKX 写的一致。

## 在管道中

交易对的**成交**和每个**K线**系列都可以作为管道中持续读取的连线的起点：**将新消息追加到表**或**追加到新表**，或**按键保留最新**。每次运行只读取上次以来的新数据，开启的管道会在几秒内把它们送达。

- 每条连线停在哪里由 DataPlayer 记录；OKX 不记录。
- **首次运行读取**：**仅新数据**从现在开始；**从最早可用**从最近一小时的成交开始，或从最近一天的K线开始。
- K线在收盘后才会被读取。
- 超过三个月未运行的连线会发现最早的成交已被 OKX 删除；运行会说明跳过了多少笔。
- 连线创建的表以成交的 **id** 或K线的 **open_time** 为键，因此不会重复。

## 你的账户

有密钥时，每个市场都有**账户**：交易账户的**余额**（每个市场相同）、期货的**持仓**、**当前委托**，现货还有**充值**和**提现记录**。交易对多出最近七天的**我的订单**和最近三天的**我的成交**。**我的成交**可以像**成交**一样作为管道链接的起点。

- 请在 OKX 上创建只带 **Read** 权限的密钥。也能交易或提现的密钥会被接受，检查会提示这一点：DataPlayer 只读取，但只读密钥更安全。
- 如果密钥限定了地址，请加入 DataPlayer 服务器的地址。
- **交易所**中的 **API 密钥**说明 OKX 允许该密钥做什么。

## 交易所

- **状态**：端点、OKX 是否宣布交易维护，以及每个市场是否响应。
- **时钟**：每个市场的时间以及它领先 DataPlayer 服务器多少。
- **请求限额**：对已发出的每类请求，OKX 在其窗口内允许的数量、已使用量、DataPlayer 的停止点，以及请求是否被暂停。
- **市场**：有多少交易对在交易、涉及多少种计价资产，以及列表的读取时间；一小时后会重新读取。
- **API 密钥**：密钥是否只读、能否交易或提现，以及是否限定了地址。

## 仪表板和搜索

- **OKX 连接**仪表板绘制每类请求在其窗口内的数量与 DataPlayer 停止点的对比、OKX 的响应时间，以及每个市场是否响应。上面没有价格：用管道把价格送入表格，再绘制那张表。
- 搜索按名称和资产查找交易对：`btc` 会找到 BTC-USDT 和 ETH-BTC，名称匹配优先。在某个计价资产内搜索只限于该资产。交易对可以保留用于全局搜索。

## 请求限额

OKX 对每类请求分别限额：两秒内若干次——K线 20 次、成交 20 次、订单簿 40 次。DataPlayer 自行统计请求，在每项限额的 40% 处停止，因此任何两秒内都不会超过 80%；超出的请求会等待下一个两秒而不是失败，所以较长的下载会多花几秒。如果 OKX 仍然拒绝该地址，这类请求会等待两秒。
