# 文件

你在此服务器上的个人存储：一个属于你的文件夹，其他人无法访问，除非你与某人共享了
指向它的连接。你可以浏览文件夹、在合适的查看器中打开文件、修改文件，以及导入和
导出文件。连接的一般工作方式见[连接](connections.md)页面。

## 你可以看到的内容

- 文件夹和文件，以及它们各自是什么：大小、日期、格式
- CSV、TSV、Excel 和 Parquet 文件中的表，以及日志中的表
- 文档、代码、图像、PDF、录音，以及 zip 压缩包的内容
- 按名称或按所含文本找到的文件
- 对保存在文件中的表执行的 SQL

## 你可以更改的内容

- 在文本编辑器中修改文件
- CSV 和 TSV 文件的行与列
- 文件和文件夹：创建、上传、重命名、删除、下载
- 压缩包：将文件打包成一个，或从中解压
- 在文件夹和连接之间复制或移动文件

## 连接

唯一的字段是**路径**：连接所打开的个人存储文件夹。`/` 是存储的根目录，
`/reports/2026` 是它包含的一个文件夹。存储之外的任何内容都不可访问。

目录操作菜单中的**连接文件夹**会创建一个打开到该文件夹的新连接。

## 目录

- 你所在层级的路径显示在顶部。**复制此层级的路径**会以**路径**字段采用的形式复制
  它。
- **此连接的根目录**会回到连接打开的位置。
- 筛选字段会按名称缩小当前层级。
- 旁边的搜索按钮会在下方所有文件夹中按名称查找相同的词。按住 **Shift** 点击它，
  可搜索文件内部；第一次会说明这样做的开销并请求确认。匹配项会显示找到它的那一
  行。**返回文件夹**会退出结果。
- 点击文件会在标签页中打开它。点击文件夹、工作簿或 zip 压缩包会进入其中。
- 操作菜单中的**详细信息**会说明文件或文件夹是什么：大小、日期、权限、可以以何种
  方式打开，以及其格式本身能说明的内容（Parquet 文件的列、工作簿的工作表、
  录音的时长、图像的大小）。

## 打开文件

文件会在合适的查看器中打开。如果有多种打开方式，其他方式会显示在上方。

- **CSV 和 TSV** 以表的形式打开。每一列都是文本。
- **Excel 工作簿**（`.xlsx`、`.xlsm`）会在第一个可见工作表上打开。其他工作表位于
  表格底部，就像电子表格放置它们的位置。公式显示文件中最后保存的值。
- **Parquet** 以表的形式打开，并采用文件声明的列类型。
- **JSON** 和 **JSON lines** 以文本形式打开，**以表格显示**会将它们转换为行。
- **日志**（`.log`）以文本形式打开，**以表格显示**会将每一行拆分为时间、级别和
  消息。
- **Markdown** 以文档形式打开，带有目录、代码、公式、图表和示意图。**导出**会将
  它保存为 HTML 页面或将其打印。
- **文本和代码**会在带语法高亮的编辑器中打开。
- **图像**、**PDF**、**音频**和**视频**会在各自的查看器中打开。PDF 可以搜索。
- **zip 压缩包**会以文件夹形式打开，其中的文件会像其他文件一样以只读方式打开。

来自文件的表可以像表格中的任何表一样读取（表格本身见 [PostgreSQL](source-postgres.md)），
但有两个区别：文件无法排序，筛选只能匹配精确值。

## 修改

- 文本、JSON、JSON lines 或 Markdown 文件会在编辑器中打开。**保存**会重写它。
  JSON 文件必须保持有效才能保存。
- 如果文件自你打开以来已发生变化，保存会被拒绝，不会写入任何内容。**重新加载
  文件**会重新读取它。
- 最大 4 MB 的文件可以修改。更大的文件会以只读方式打开并说明原因。
- 在 CSV 或 TSV 表中，你可以修改单元格、插入行、删除勾选的行，并从**结构**中添加、
  重命名或删除列。

## 文件与文件夹

目录的操作菜单会针对你所在的层级或已勾选的内容提供：

- **新建文件夹**、**新建文件**、**上传文件**。上传时会说明名称已存在时的处理方式：
  停止、替换文件，或保留两者并使用新名称；
- **重命名**、**删除**。没有回收站：删除的文件会丢失；
- **下载**：单个文件按原样下载；文件夹或多个勾选的文件会打包成一个 zip 压缩包；
- **归档**：将勾选的内容打包为 zip、tar、tar.gz、tar.bz2 或 tar.xz；
- **解压**：将压缩包解压到此处，或解压到专用文件夹；
- **复制**和**剪切**，然后**粘贴**到你想要的位置。这可以在同一连接的文件夹之间以及
  不同连接之间使用，包括 SSH 服务器。将数据库中的表粘贴到文件夹中，会将其保存为
  CSV 文件。

跨连接的复制在后台执行。活动铃铛会显示其进度，并可以停止它。

## 对文件执行 SQL

在表上方选择**作为查询打开**，或在左侧边栏的**查询**中选择**新建查询**，会在该
连接上启动 SQL 控制台。表通过其路径以双引号命名，例如
`SELECT * FROM "sales/2026.csv"`。CSV、TSV、Parquet、JSON、JSON lines 和日志
文件可以查询和连接；Excel 工作表目前还不行。查询所做的任何事都不会写回文件。

## 限制

- 编辑器可容纳最大 4 MB 的文件。
- 文件内部搜索会忽略大于 8 MB 的文件，并在读取 256 MB 后停止。
- 一个文件夹最多列出 2000 个条目。
- 压缩包中的文件最多读取 32 MB。
- 一次下载或一个压缩包最多包含 10 000 个文件和 2 GB。
