# SSH

通过 SSH 访问的服务器。你可以像使用自己的文件一样浏览其文件夹并处理其文件：表、
对文件执行 SQL、编辑器、压缩包、搜索、跨连接复制以及终端。连接使用密码或你的某个
SSH 密钥进行，并且只连接到你已确认密钥的服务器。连接的一般工作方式见
[连接](connections.md)页面。

## 你可以看到的内容

- 从你选择的位置开始的服务器文件夹和文件
- CSV、TSV、Excel 和 Parquet 文件中的表，以及日志中的表
- 文档、代码、图像、PDF、录音，以及 zip 压缩包的内容
- 按名称或按所含文本找到的文件
- 对保存在文件中的表执行的 SQL

## 你可以更改的内容

- 在文本编辑器中修改文件
- CSV 和 TSV 文件的行与列
- 文件和文件夹：创建、上传、重命名、删除、下载
- 压缩包：将文件打包成一个，或从中解压
- 在文件夹和连接之间复制或移动文件
- 其他所有内容，从服务器上的终端进行

## 连接

窗口的**连接**页面会询问：

- **主机**和**端口**，除非服务器另有说明，否则为 22；
- **用户**：用于登录的账户；
- **文件夹**：浏览开始的位置。留空表示账户的个人文件夹；
- **服务器密钥**：服务器用来证明其身份的内容（见下文）；
- **身份验证**：密码，或**密钥**，即你的某个 SSH 密钥。

将类似 `ssh://ann@files.example.com:22` 的连接字符串粘贴到 **URL** 中会填充
主机、端口和用户。密码永远不会包含在其中。

### 服务器密钥

在你确认服务器密钥之前，不会向服务器发送任何内容。这可以防止密码或密钥发送到
一台仅仅冒充你服务器的机器。

1. 填写主机和端口，然后点击**从服务器获取**。
2. 会显示服务器的指纹。将其与服务器管理员提供的内容或 `ssh-keyscan` 显示的
   内容进行比较。
3. 点击**信任此密钥**。

如果服务器随后提供不同的密钥，它会被拒绝，并附有说明原因的提示。如果服务器已被
重新安装，请重新获取其密钥，进行比较，然后点击**信任新密钥**。只有连接所有者才
能这样做。

通过**在此启动 SSH 服务器**启动的服务器会信任它首先提供的密钥，因为此应用程序
启动了它。

### SSH 密钥

你的 SSH 密钥位于**偏好设置**页面，与连接分开，这样一把密钥就可以用于你指向它
的任意多个连接。

- **新建密钥**会在此服务器上创建密钥：ED25519，或对于拒绝 ED25519 的服务器使用
  RSA。**导入**会采用你粘贴或选择为文件的私钥。
- **复制公钥**会复制要添加到服务器 `~/.ssh/authorized_keys` 中的那一行。它以
  `dataplayer` 结尾，以便服务器所有者能分辨它来自哪一行。
- 密钥的私有部分不会再向任何人显示。
- 密钥可以有密码短语，通过三种方式之一保存：不保存；与密钥一起存储；或在需要
  密钥时询问，并保留 15 分钟、一小时或八小时。**立即锁定**会提前忘记它。
- 已锁定的密钥会停止其连接。每个读取该连接的屏幕随后会提供**解锁密钥**，而不是
  显示错误。
- 正在被连接使用的密钥无法删除。请先将连接指向另一把密钥。

## 目录与文件

SSH 连接的浏览方式与[文件](source-file.md)连接完全相同：相同的目录、相同的按
名称和文件内部搜索、相同的查看器、相同的编辑器、相同的操作（**新建文件夹**、
**新建文件**、**上传文件**、**重命名**、**删除**、**下载**、**归档**、**解压**、
**复制**、**剪切**、**粘贴**），以及对文件执行相同的 SQL。

以上操作都不会在服务器上执行命令：一切都通过 SFTP 进行。

与你自己的文件相比的区别：

- 不提供**连接文件夹**。
- 大于 200 MB 的文件不会作为表、工作簿、压缩包或 SQL 打开：请改为下载它。文本、
  图像、PDF 和录音无论大小都可以打开。
- 文件内部搜索会忽略大于 1 MB 的文件，并在总共 32 MB 后停止，因为每个字节都要
  经过网络传输。

## 终端

左侧边栏的**终端**会在屏幕底部的面板中打开一个终端：即连接所用账户在服务器上的
登录 shell。

- 只有连接所有者才能打开一个终端。与该连接共享的人不能打开。
- shell 会从账户的个人文件夹启动，而不是连接的**文件夹**。
- 关闭终端、关闭页面或网络中断都会结束 shell。它不会被重新连接；请再打开一个。
- 可以同时打开多个终端，最多八个。切换到面板中的其他工具会让它们继续运行。
