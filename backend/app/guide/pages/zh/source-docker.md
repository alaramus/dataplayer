# Docker

另一台机器上的 Docker 守护进程，通过你的某个 SSH 连接访问。你可以看到它的容器、镜像、卷和网络，守护进程对每一项的说明，容器的日志和进程，以及守护进程自身的报告。连接的一般说明见[连接](connections.md)页面。

## 你可以看到的内容

- 按 Compose 项目分组的容器，无论是否在运行
- 镜像、卷和网络，以及使用它们的容器
- 守护进程对其中任意一项的说明，以 JSON 树显示
- 容器的日志（最新在前）以及其中运行的进程
- 镜像的层以及创建这些层的指令
- 引擎：版本、驱动、CPU、内存、磁盘占用、近期事件

## 你可以更改的内容

- 启动、停止、重启、暂停、取消暂停或强制终止容器
- 一次操作 Compose 项目的所有容器
- 删除容器、镜像、卷和网络
- 清理已停止的容器以及未使用的镜像、卷和网络
- 新建卷和网络
- 拉取公共镜像，将容器提交为镜像

## 连接

守护进程从不直接访问。先为它所在的机器创建一个 **SSH 连接**，然后 Docker 连接的**连接**页面会要求填写：

- **SSH 连接**：你的某个 SSH 连接。其账户必须能使用守护进程的套接字——在大多数机器上，它属于 `docker` 组；
- **套接字**：守护进程在该机器上监听的位置。Docker 为 `/var/run/docker.sock`，无 root 的 Docker 为 `/run/user/<uid>/docker.sock`。**Podman** 卡片会填入 `/run/podman/podman.sock`；无 root 的 Podman 使用 `/run/user/<uid>/podman/podman.sock`，且其套接字必须已开启（`systemctl --user enable --now podman.socket`）。

套接字通过 SSH 连接转发，就像通过 SSH 隧道访问数据库一样；SSH 服务器必须允许这样做（`AllowStreamLocalForwarding`，默认开启）。如果检查提示套接字无法打开，说明以下三者之一有问题，而 OpenSSH 不会说明是哪一个：该路径上没有程序在监听、账户无权使用它，或转发已关闭。

守护进程必须支持 API 1.41 或更新版本（Docker 20.10 及以后）。

运行 DataPlayer 本身的机器上的 Docker 守护进程永远不会提供：掌握该套接字的人就掌握了这台机器。

## 目录

- **系统**包含守护进程的报告，见下文。
- **容器**中每个 Compose 项目一个文件夹，按 Compose 写入的标签命名，其余容器在**独立容器**中。每个容器用一个词显示其状态——运行、健康、不健康、启动中、已暂停、重启中、已停止、失败、已创建或已死亡——旁边是守护进程自己的状态、镜像、Compose 服务和已发布端口。
- **镜像**按 id 列出每个镜像，无论是否有标签，并显示大小以及使用它的容器数。
- **卷**按名称列出每个卷；**网络**列出每个网络，Docker 自带的三个排在最前，每个标记为内置、Compose 或用户。
- 这些文件夹也都可以作为表格打开，可按任意列筛选和排序。同一类超过一万个时不再列出。

## 节点如何打开

- 容器、镜像、卷或网络以守护进程对它的说明打开，显示为 JSON 树。容器的说明包含其环境变量，其中常有密码：与你共享此连接的任何人都能看到。
- 容器内：**日志**——每行的时间、流（stdout 或 stderr）和文本，最新在前，最多回溯一万行，单行在 16 KB 处截断——以及**进程**，即当前在其中运行的内容。已停止的容器没有进程。
- 镜像内：**历史**，即它的层。
- 卷或网络内：**容器**，即使用它的容器。

## “系统”部分

- **引擎**：守护进程的版本、操作系统、内核、驱动、CPU、内存以及容器和镜像数量，使用守护进程自己的字段名。镜像仓库镜像和代理不显示：其中可能含有密码。
- **磁盘占用**：每个镜像、容器、卷和构建缓存条目的大小，以及删除它是否能释放空间。守护进程需要测量每个卷才能回答，因此可能较慢。
- **事件**：过去一小时内发生的事，最新在前。

## 被拒绝时

- SSH 连接或套接字的拒绝会使整个连接停止，每个页面都会说明原因。
- 位于授权插件或过滤代理之后的守护进程可能拒绝单个请求：此时会显示 **Docker 服务器不允许此操作**。

## 更改

选择一个容器、一个 Compose 项目文件夹或一个节点，然后打开目录菜单。容器的生命周期操作需要写权限；删除、清理、拉取、提交以及新建卷和网络需要结构权限。

- **启动**、**停止**、**重启**、**暂停**、**取消暂停**和**强制终止**作用于所选容器，或所选 Compose 项目的全部容器。每项操作都会先列出将要做什么，以及哪些容器已处于该状态。停止和重启可以在终止前等待若干秒；强制终止会发送你选择的信号。
- **删除容器**在未勾选**强制**时不会删除正在运行的容器，并可同时删除其匿名卷。**删除镜像**会列出使用它的容器；**删除卷**不会删除被挂载的卷；**删除网络**不会删除仍有容器的网络，也不会删除 Docker 自带的三个网络。
- 在**容器**、**镜像**、**卷**和**网络**中，清理会列出将被删除的内容，镜像还会显示释放的空间。守护进程删除的是点击时未被使用的对象，因此期间变为未使用的也会被删除。
- **新建卷**和**新建网络**位于**卷**和**网络**中。
- **镜像**中的**拉取镜像**和容器上的**提交为镜像**会作为任务在**活动**中运行。只能拉取公共镜像：需要登录的仓库不受支持。

## Docker 在这里还没有的功能

- 容器内的终端，以及实时跟随的日志
- 仪表板上的指标，以及搜索
- 通过 TLS 而非 SSH 访问守护进程
- 私有仓库，以及创建或运行新容器
