# FTP

通过 FTP 或 FTPS 访问的服务器。你可以从选定的位置浏览其文件夹，像处理自己的文件一样
处理其中的文件：表、文件上的 SQL、查看器和搜索。使用密码或匿名登录。连接的一般工作方式见
[连接](connections.md)页面。

## 你可以看到的内容

- 所选文件夹下的文件夹和文件
- CSV、TSV、Excel 和 Parquet 文件以及日志中的表
- 文档、代码、图片、PDF、录音录像以及 zip 归档的内容
- 按名称或按其中文本找到的文件
- 对文件中的表运行 SQL

## 你可以更改的内容

- 在文本编辑器中编辑文件
- CSV 和 TSV 文件的行和列
- 文件和文件夹：新建、上传、重命名、删除、下载
- 归档：将文件打包为一个，或解压一个
- 在文件夹和连接之间复制或移动文件

## 连接

窗口的**连接**页面会要求填写：

- **主机**和**端口**：21，隐式 TLS 为 990；
- **加密**：**TLS，显式**是如今大多数服务器使用的方式，端口 21。**TLS，隐式**是较老的
  FTPS，端口 990。**不加密**会按原样发送密码：仅在服务器不提供其他方式时选择；
- **验证证书**：仅对使用自制证书的服务器关闭；
- **文件夹**：浏览的起点。留空为服务器登录后所在的文件夹，`/` 为服务器的顶层；
- **身份验证**：**用户**和**密码**，或对公共服务器选择**匿名**。

**URL** 将服务器显示为 `ftp://user@host/folder`，隐式 TLS 为 `ftps://`。粘贴到其中的
地址会填写主机、端口、用户和文件夹。密码永远不会出现在地址中。

## 目录与文件

FTP 连接的浏览方式与[文件](source-file.md)连接相同：相同的目录、相同的按名称和在文件
内的搜索、相同的查看器和相同的文件上的 SQL。操作也相同：**新建文件夹**、**新建文件**、**上传文件**、**重命名**、**删除**、
**下载**、**归档**、**解压**、**复制**、**剪切**和**粘贴**。

FTP 服务器与磁盘的不同之处：

- 你能读取和更改什么，由服务器自身的权限决定。
- 名称不是 UTF-8 的文件不会显示，它仍在服务器上。
- 有些服务器只给出精确到分钟的时间，较旧的文件只给出日期，且都不说明时区：时间按 UTC 显示。
- 大于 200 MB 的文件不会作为表、工作簿、归档或在 SQL 中打开：请下载它。文本、图片、PDF
  和录音录像无论大小都能打开。
- 在文件内搜索会跳过大于 1 MB 的文件，总计 32 MB 后停止，因为每个字节都要经过网络。
- 复制会让每个字节经过 DataPlayer，因为 FTP 没有自己的复制：一次最多 200 MB。
- 保存到一个期间已被更改的文件上时会被拒绝，而不是覆盖。
