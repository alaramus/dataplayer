# MongoDB

MongoDB 服务器。你可以浏览它的数据库和集合，并按页以行的形式读取文档；集合的字段由其文档确定。连接的一般说明见[连接](connections.md)页面。

## 你可以看到的内容

- 数据库、集合、视图和时间序列
- 以行显示的文档，由服务器排序和筛选
- 集合中文档的字段及其索引
- 集合的定义：选项、验证器和索引，以 JSON 显示
- 每个完整文档，以 JSON 按页显示
- 集合包含多少文档、占用多少空间
- 在终端中以连接身份登录的 mongosh
- 所有匹配的文档，下载为文件
- 服务器的操作、连接、用户和角色
- 仪表板上的服务器计数器

## 你可以更改的内容

- 文档：编辑字段、粘贴块、添加和删除文档
- 每个文档中的字段：添加、删除、重命名、转换类型
- 索引：普通和唯一、哈希、文本和地理空间索引
- 数据库和集合：创建、重命名、移动、删除；加载 CSV
- 正在运行的操作：在其报告中停止
- 将集合连同索引复制到另一个 MongoDB 连接
- 连接的数据库：备份到文件并从文件恢复
- mongosh 能更改的一切，在它的终端中输入

## 连接

窗口的 **连接** 页面需要填写：

- 一台服务器的 **主机** 和 **端口**，默认 27017；
- **TLS**：加密连接，并验证服务器证书；
- **认证**：用户和密码，或者对未启用访问控制的服务器不填。**认证数据库** 是创建该用户的数据库，默认为 `admin`；
- **数据库**：目录打开的位置，可以留空。

粘贴到 **URL** 的连接字符串（如 `mongodb://ann@db.example.com:27017/shop`）会填写这些字段；也会读取 `?authSource=` 和 `?tls=true`。

所填服务器就是要连接的服务器。副本集成员按原样读取；要修改数据，请填写主节点。不支持 `mongodb+srv://` 地址和服务器列表。支持 MongoDB 5.0 及更高版本。

## 目录

- 第一层是数据库。连接所指定的数据库排在最前，即使其中还没有任何内容；`admin`、`local` 和 `config` 属于服务器。
- 数据库中是它的集合和视图，并显示文档数量和大小。

## 以行显示的文档

- 集合的列就是其文档的字段：验证器声明的字段，以及在最前和最后各一百个文档中找到的字段。`_id` 排在最前。只在其他文档中出现的字段会在其所在页面显示，但不能排序或筛选。
- 每一列显示其值的类型；文档之间不一致的字段为混合类型。
- ObjectId 以十六进制显示，日期以带 `Z` 的 UTC 显示，对象和数组以 `mongosh` 的写法显示为 JSON。
- 缺少的字段和值为 null 的字段都显示为空单元格。
- 筛选值按字段保存值的方式读取；看起来像查询的文本仅仅是文本。
- 未自行排序时，页面按 `_id` 排序。

## 修改文档

- 单元格是一个文档的一个字段；输入的内容按字段保存值的方式存储，对象或数组以 JSON 存储。
- 页面读取后被他人修改的文档不会被覆盖：你会收到提示，页面会重新读取。
- `_id` 不能修改。清空单元格会存储 null。
- 粘贴的块先整体检查，再逐个文档写入；一组新文档要么全部插入，要么都不插入。
- **以文档形式查看** 显示每个完整文档。

## 结构

集合的列就是其文档的字段，因此结构界面会同时更改所有文档。更改类型时会先统计无法转换的值，只要有一个就不做任何更改。值重复时不会创建唯一索引。

## 目录操作和 Server 区域

- **新建数据库** 还会询问第一个集合的名称。
- 集合可以重命名、移动到另一个数据库或删除；视图只能删除。
- **从 CSV 加载** 创建一个集合，所有值都是文本。
- **Server** 区域包含操作、连接、用户和角色；**停止操作** 会停止在“操作”中选中的项。

## 副本、备份和自己的服务器

- **复制表** 将集合连同选项、每个文档和索引复制到另一个 MongoDB 连接。
- 备份是 `mongodump` 的归档；恢复使用 `mongorestore`。不支持通过 SSH 隧道。
- **服务** 可以启动你自己的 MongoDB，并用 `demo_lab` 填充。

## mongosh

在你自己的 MongoDB 连接上 **打开终端** 会启动 `mongosh`，以连接身份登录，运行在此服务器启动的容器中；不支持通过 SSH 隧道。关闭终端或输入 `exit` 即可结束。
