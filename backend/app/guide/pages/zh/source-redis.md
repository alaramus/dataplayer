# Redis

一个内存中的键值服务器。你可以浏览其键，键会根据名称中的冒号构成树形结构，以行的
形式读取键的内容，写入各种类型的键，并设置或删除它们的过期时间。连接的一般工作
方式见[连接](connections.md)页面。

## 你可以看到的内容

- 服务器上的每个数据库，以及以树形结构显示的键
- 键的内容，以行形式显示：字段、list 元素、set 元素、分数、条目
- 键的类型、大小以及剩余存活时间
- 将哈希文件夹显示为一张表
- 仪表盘上的服务器指标

## 你可以更改的内容

- 键内部的值，一次一个
- 六种类型的键：创建、替换、删除
- 键的过期时间：设置或删除
- 在哈希文件夹上声明的表
- 将键保存为 CSV 文件

## 连接

窗口的**连接**页面会询问：

- **主机**和**端口**，除非服务器另有说明，否则为 6379；
- **数据库**：目录打开时所处的数据库。所有数据库仍可从目录访问；
- **身份验证**：密码，或无。

将类似 `redis://:secret@cache.example.com:6379/0` 的连接字符串粘贴到 **URL**
中会填充这些字段。需要 TLS 的 `rediss://` 地址尚不支持。

## 目录

目录是一棵树。

- 顶部的命令选择数据库。它会显示每个数据库包含多少个键。选择会在此浏览器中
  记住。
- 键会根据名称中的冒号分组：`session:42:token` 位于 `session` 下，然后位于
  `42` 下。点击文件夹会在原地打开它。
- 键会显示其类型、大小，如果会过期，还会显示剩余时间。
- 点击键会在标签页中打开它。点击一行会选中它，操作菜单随后会作用于它。
- 非常大的键空间会列出到某个上限。更窄的文件夹会显示超出范围的内容。

## 读取键

键以行形式打开。形式取决于其类型：

- **string** 是单个值；
- **hash** 是字段和值；
- **list** 是位置和值；
- **set** 是元素；
- **sorted set** 是元素和分数；
- **stream** 是条目。

行会像表格中的任何表一样分页。Redis 没有值索引，因此无法排序或筛选。
**下载**可以将每一行保存为 CSV 文件。

## 修改键

拥有**修改行**权限时，键的值会在其表格中修改：

- 双击单元格可修改 hash 字段、list 元素、string 或分数；
- **插入行**会添加一个字段、list 元素或 set 元素；
- 勾选行并点击**删除选中的行**会删除字段和元素。

每种类型允许什么由表格本身显示。无法从 list 中间移除元素，stream 完全无法修改。

如果有人在读取值后修改了它，你的修改会被拒绝，而不会覆盖对方的修改。请重新加载
后重试。

## 写入键

在树中选择文件夹或键并打开操作菜单：

- **新建 string 键**、**新建 hash 键**、**新建 list 键**、**新建 set 键**、
  **新建 sorted set 键**、**新建 stream 键**。你输入的名称会添加到当前所在的
  文件夹，因此在 `cache:` 中写入 `one` 会变成 `cache:one`。集合每行写入一个元素
  或一个 `name=value`。可以立即设置过期时间。已使用的名称会被拒绝，除非你选择
  替换它；
- **删除**会移除一个键，之前会要求确认；
- **设置过期时间**会为键赋予存活时间，**移除过期时间**会将其移除。

## 复制到外部

在目录中**复制**一个键、文件夹或数据库，并将其**粘贴**到文件或 SSH 连接的文件夹
中：每一个都会变成 CSV 文件。多个勾选的元素会一起复制，每个元素一个文件。你也
可以将一个键、文件夹或数据库的所有行导出为 CSV。

## 指标

Redis 连接可以向仪表盘报告自己的计数器：内存、客户端、命令、成功和失败、过期和
被逐出的键、网络流量以及每个数据库的键数。所有者会在**仪表盘**工作区的**数据源**
窗口中启用它，并选择频率。预设布局称为 **Redis 服务器**。

## redis-cli

在你自己的 Redis 连接上 **打开终端** 会启动 `redis-cli`，以连接身份登录并进入其数据库，运行在此服务器启动的容器中；不支持通过 SSH 隧道。关闭终端或输入 `quit` 即可结束。

## Redis 在这里不提供什么

- 键在标签页打开期间过期时，仍会留在屏幕上，直到标签页重新读取。
- 值以文本显示。包含图像的键会显示为无法读取的字符。
