# S3

Amazon S3，或任何兼容其 API 的存储。你可以浏览存储桶和文件夹，像处理自己的文件一样
处理对象：表、文件上的 SQL、查看器和搜索。使用访问密钥登录。连接的一般工作方式见
[连接](connections.md)页面。

## 你可以看到的内容

- 存储桶，以及其中的文件夹和对象
- CSV、TSV、Excel 和 Parquet 文件以及日志中的表
- 文档、代码、图片、PDF、录音录像和 zip 归档的内容
- 按名称或按其中文本找到的对象
- 对存放在对象中的表运行的 SQL

## 你可以更改的内容

- 在文本编辑器中编辑对象
- CSV 和 TSV 文件的行和列
- 对象和文件夹：创建、上传、重命名、删除、下载
- 归档：把对象打包成一个，或解包一个
- 在文件夹和连接之间复制或移动的对象
- 存储桶：创建一个，或连同内容删除一个

## 连接

窗口的**连接**页面会要求填写：

- **接入点**：存储的地址，例如 `https://s3.example.com`。留空即 Amazon S3；
- **区域**：从 Amazon 给出的列表中选择；端点指向其他存储时手动输入；留空即 `us-east-1`；
- **访问密钥**和**私钥**；
- **存储桶**：留空则显示该密钥可列出的所有存储桶；
- **文件夹**：在存储桶内从哪里开始浏览；
- **寻址方式**：“auto”在 Amazon S3 上为 virtual-hosted，其他地方为 path-style，
  所有兼容存储都接受；
- **验证证书**：仅当存储的证书是你自己制作的时才关闭。

**AWS 账号**改用您的某个[云账号](cloud-accounts.md)登录而非密钥：会话令牌、要代入的角色或本服务器自己的凭据都属于该账号。

**URL** 显示存储所在的位置：它的接入点，或该区域的 Amazon S3 地址。粘贴到其中的地址会
填入接入点，Amazon S3 URL 还会填入区域；`s3://reports/2026` 会填入存储桶和文件夹。
存储桶和文件夹不会在 URL 中重复，密钥也永远不在其中。

类型目录为每个提供商显示一张卡片：Amazon S3、MinIO、RustFS、Cloudflare R2、Backblaze B2、
Wasabi、DigitalOcean Spaces、Google Cloud Storage、Yandex Object Storage、VK Cloud、
Selectel 和 Hetzner Object Storage。每张卡片都是同一个表单：它填入提供商始终相同的
内容，并说明其余内容在哪里找到。它们都不会启动服务器。

## 目录与对象

S3 连接的浏览方式与[文件](source-file.md)连接相同：相同的目录、相同的按名称和在文件
内的搜索、相同的查看器和相同的文件上的 SQL。操作也相同：**新建文件夹**、**新建文件**、**上传文件**、**重命名**、**删除**、
**下载**、**归档**、**解压**、**复制**、**剪切**和**粘贴**。

存储与磁盘的不同之处：

- 文件夹是若干键的共同开头，例如 `reports/2026/`。空文件夹是一个键以 `/` 结尾的空
  对象，各提供商自己的控制台也是这样创建的。
- 不能作为文件名的键——含有空段、`.` 或 `..`、反斜杠，或像 `C:` 这样的盘符——不会
  显示。它仍留在存储桶中。
- 大于 200 MB 的对象不会作为表、工作簿、归档或在 SQL 中打开：请下载它。文本、图片、
  PDF 和录音录像无论大小都能打开。
- 在对象内搜索会跳过大于 1 MB 的对象，总量达到 32 MB 后停止，因为每个字节都要经过
  网络。
- 归档存储类中的对象需要先恢复才能读取。
- 重命名或移动文件夹会复制其中每个对象再删除旧的：存储无法重命名。一次最多移动、
  复制或删除 10,000 个对象；更大的文件夹会被拒绝。
- 在你编辑期间已被更改的文件不会被覆盖：保存会被拒绝。

### 存储桶

当**存储桶**为空时，目录顶层列出的是存储桶。

- 在那里**新建存储桶**会在连接的区域中创建存储桶。名称由 3 到 63 个小写字母、数字、
  点和连字符组成，并以字母或数字开头和结尾。
- **删除**会连同全部内容删除存储桶，最多 10,000 个对象。保留对象旧版本的存储桶会被
  拒绝：请先用生命周期规则清空它。
- 存储桶不能重命名：存储没有这种操作。**复制**或**剪切**一个存储桶，再把它**粘贴**到另一个
  存储桶的文件夹中，它的对象就会出现在那里一个以它命名的文件夹里；被剪切的存储桶清空后会被删除。
- 顶层只有存储桶，所以那里不提供新建文件、上传文件和粘贴。存储桶有自己的图标。
