# S3

Amazon S3，或任何兼容其 API 的存储。你可以浏览存储桶和文件夹，像处理自己的文件一样
处理对象：表、文件上的 SQL、查看器和搜索。使用访问密钥登录。连接的一般工作方式见
[连接](connections.md)页面。

## 你可以看到的内容

- 存储桶，以及其中的文件夹和对象
- CSV、TSV、Excel 和 Parquet 文件以及日志中的表
- 文档、代码、图片、PDF、录音录像和 zip 归档的内容
- 按名称或按其中文本找到的对象
- 对存放在对象中的表运行的 SQL

## 连接

窗口的**连接**页面会要求填写：

- **接入点**：存储的地址，例如 `https://s3.example.com`。留空即 Amazon S3；
- **区域**：留空即 `us-east-1`；
- **访问密钥**和**私钥**；
- **存储桶**：留空则显示该密钥可列出的所有存储桶；
- **文件夹**：在存储桶内从哪里开始浏览；
- **寻址方式**：“auto”在 Amazon S3 上为 virtual-hosted，其他地方为 path-style，
  所有兼容存储都接受；
- **验证证书**：仅当存储的证书是你自己制作的时才关闭。

## 目录与对象

S3 连接的浏览方式与[文件](source-file.md)连接相同：相同的目录、相同的按名称和在文件
内的搜索、相同的查看器和相同的文件上的 SQL。**下载**取回一个对象，或将文件夹打包为
归档取回。

存储与磁盘的不同之处：

- 文件夹是若干键的共同开头，例如 `reports/2026/`。空文件夹是一个键以 `/` 结尾的空
  对象，各提供商自己的控制台也是这样创建的。
- 不能作为文件名的键——含有空段、`.` 或 `..`、反斜杠，或像 `C:` 这样的盘符——不会
  显示。它仍留在存储桶中。
- 大于 200 MB 的对象不会作为表、工作簿、归档或在 SQL 中打开：请下载它。文本、图片、
  PDF 和录音录像无论大小都能打开。
- 在对象内搜索会跳过大于 1 MB 的对象，总量达到 32 MB 后停止，因为每个字节都要经过
  网络。
- 归档存储类中的对象需要先恢复才能读取。
