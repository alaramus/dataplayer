# Cassandra

通过 CQL 连接的 Apache Cassandra 或 ScyllaDB 集群。你可以浏览它的键空间，分页读取表和物化视图，查看表的键如何构成，并阅读服务器生成的 DDL。两个产品是同一种连接类型：类型目录为每个产品显示一张卡片，连接会说明它连到的是哪一个。连接的一般说明见[连接](connections.md)页面。

## 你可以看到的内容

- 键空间、表和物化视图
- 分页显示的行，由服务器筛选，值与存储时完全一致
- 表的分区键、聚簇列和二级索引
- 服务器生成的关系 DDL
- Cassandra 的虚拟表，例如 `system_views`
- 你在控制台或 cqlsh 中编写的 CQL 的结果
- 集群的节点、客户端、表大小、设置和角色
- 下载为文件的所有匹配行
- 仪表板上节点的客户端、请求和大小

## 你可以更改的内容

- 表数据：编辑单元格、粘贴块、插入和删除行
- 表的列和二级索引
- 用设计器设计带分区键和聚簇键的新表
- 键空间：创建和删除；表：清空和删除
- 连同结构复制到另一个 Cassandra 连接的表
- 在控制台中通过 CQL 更改数据和结构，每次一项更改

## 连接

窗口的**连接**页面会询问：

- 原生协议的**主机**和**端口**，除非服务器另有设置，否则为 9042；
- **TLS**，按主机验证服务器证书；
- **身份验证**：用户名和密码，或者对于不检查密码的服务器不填。新的 Cassandra 或 ScyllaDB 通常是 `cassandra`，密码为 `cassandra`；
- **键空间**：目录从哪里打开，可以留空；
- **一致性**：有多少副本响应读取并确认写入。除非另选，否则为 `LOCAL_ONE`。

在 **URL** 中粘贴 `cassandra://ann@db.example.com:9042/shop` 这样的连接字符串会填好这些字段；也能读取 `scylla://`，`?ssl=true` 开启 TLS，`?consistency=LOCAL_QUORUM` 选择级别。

每条语句都发送到你指定的节点，即使集群还有其他节点：节点自报的地址在这里常常无法访问——位于 Docker、NAT 或 SSH 隧道之后——而你指定的节点可以访问。该节点会向其他节点请求它没有的数据。

支持 Cassandra 4.0 和 ScyllaDB 5.4 及更高版本。检查连接时会拒绝更旧的服务器，并说明其版本。

## 目录

- 第一层是键空间。连接指定的键空间排在最前；`system` 和 `system_…` 键空间属于服务器并标记为系统所有，ScyllaDB 的 `audit` 也是如此。
- 键空间中是它的表和物化视图。ScyllaDB 把二级索引保存在一个隐藏视图中；该视图不列出，索引显示在其所属的表上。
- 表的列会说明哪些属于分区键、哪些是聚簇列、顺序如何、哪些是静态列。

## 行

- 行按服务器自己的顺序分页到达。任何列都不能排序：CQL 只在完整指定的单个分区内排序。
- 可以按任意列筛选。按键之外的列筛选会让服务器读取整张表，大表上可能超时。
- 筛选支持等于、大于、小于、不小于、不大于和属于列表。ScyllaDB 为文本额外提供“开头为”和“包含”；无法查找 `%` 和 `_`，因为它的 `LIKE` 没有转义。列表、集合、映射、元组、用户定义类型、blob、时长和计数器不能筛选。
- 数字与存储时完全一致，精确到 `varint` 或 `decimal` 的最后一位。时间戳以 UTC 显示。列表、集合、映射、元组和用户定义类型显示为 JSON；键不是文本的映射显示为键值对列表。blob 显示为 `0x` 加十六进制。
- 向前跳得很远时会读取中间的行，最多十万行。超过这个范围时，请从已读过的页面继续向前翻。
- 最后一页可能提示还有更多但实际为空：服务器在查看之前就会说明是否可能还有。

## CQL 控制台

左侧栏**查询**下的**新建查询**会在连接上打开一个控制台，表上方的**作为查询打开**会在该表上打开。它与 PostgreSQL 控制台的用法相同——读取、更改、补全——区别如下：

- 语言是 CQL。编辑器上方选择的键空间是未限定名称所在的键空间；`USE` 只在本次运行的剩余部分改变它。
- 没有事务。**只读**只运行读取语句：`SELECT`、`DESCRIBE` 和 `LIST`。**自动提交**运行一切，但更改行或结构的语句单独运行，因为 Cassandra 会立即保存且无法撤销。必须一起生效的更改请放进一个 `BEGIN BATCH … APPLY BATCH`，它算作一条语句。
- 参数使用 CQL 自己的写法 `:name`。服务器会说明每个参数的类型，值按该类型读取；列表、集合、映射、元组或用户定义类型以 JSON 书写。**SQL null** 发送 null。
- `CONSISTENCY`、`TRACING`、`COPY`、`SOURCE`、`PAGING` 等 cqlsh 命令不是 CQL，在这里会被拒绝；请在 cqlsh 中运行。
- **停止**只是不再等待回答。无法让服务器停止一条语句，所以它仍会执行完。

## cqlsh

连接上的**终端**会打开 cqlsh，以连接的身份登录，进入连接指定的键空间。对 ScyllaDB 使用的也是 Cassandra 的 cqlsh；两者都使用 CQL。它运行在此服务器上的容器中，因此主机必须能从那里访问；通过 SSH 隧道的连接暂时没有终端。

## 更改行

- 在表中可以编辑单元格、粘贴块、插入和删除行。物化视图、虚拟表和服务器自己的键空间只读，计数器表也是：计数器只接受加法，可以在控制台中写入。
- 行通过主键查找。键的列不能编辑——它们决定行保存在哪里——新行需要为每个键列提供值。
- 如果在你读取页面后有人更改了该行，你的更改会被拒绝而不是覆盖。请重新读取页面再做一次。与你同一时刻发生的更改无法察觉：Cassandra 没有事务来锁住该行。
- 列表、集合、映射、元组和用户定义类型按其显示的 JSON 写入；时长使用 CQL 的单位写法，例如 `1mo2d3h`。
- 静态列在整个分区中只有一个值，因此在一行上编辑它会改变该分区所有行的值。
- 插入一行时会拒绝已存在的键。成块粘贴或加载的行会替换具有相同键的行，这就是 Cassandra 的写入方式。
- 粘贴会在写入前整体检查：只要有一个值不符合其列，就什么都不改变。

## 更改结构

- 可以为表添加和删除列。主键列不能删除；被索引或物化视图读取的列，服务器也不允许删除，并会说明原因。
- 只能重命名主键列：Cassandra 不能重命名其他列。Cassandra 没有默认值、键之外的必填列和列类型更改，因此不提供这些功能。
- 二级索引建立在一列上，也可以删除。Cassandra 5 提供存储附加索引（SAI）和传统索引，ScyllaDB 提供其全局索引。都不是唯一索引。
- 物化视图、虚拟表和服务器自己的键空间不会被更改。

## 创建表

- 在键空间上选择**创建表**会打开表设计器。计划是一条 `CREATE TABLE` 加上每个索引一条 `CREATE INDEX`，运行前会显示。
- 必须有主键。在表的选项页面上，**分区键**指定主键的前几列，它们决定行保存在哪个节点上；留空时为第一列。主键的其余部分决定分区内行的顺序。
- 表名由字母、数字和下划线组成；列名可以是任何内容。列可以是其类型的列表，但列表和时长不能放进键。
- CQL 没有唯一键、外键、检查约束、默认值、计算列、排序规则、按范围、列表或哈希分区以及键之外的必填列；设计器会在请求它们的对象旁说明。

## “集群”分区

- 在键空间之后，**集群**包含节点关于集群的信息：**节点**、**客户端**、**表大小**、**设置**和**角色**。它们像表一样分页；客户端每隔几秒重新读取一次。表大小是节点自己的估算。
- `system` 键空间也在目录中，可查看这些报告未包含的内容。

## 搜索和下载

- 搜索框可以按名称查找键空间和表，也可以按列名或表注释查找表。
- 下载会获取与页面筛选条件匹配的所有行，而不只是当前页。

## 目录操作

- 连接顶层的**新建键空间**，保存在节点所在的数据中心，副本数由你选择。
- 在键空间上：**创建表**和**删除键空间**。只有在你看过其中的内容并勾选删除全部内容后，键空间才会被删除。
- 在表上：**清空**会删除所有行但保留表，以及**删除**；在物化视图上：**删除**。表会与读取它的物化视图一起删除，预览会列出这些视图。
- 表和键空间不能重命名：CQL 没有办法做到。

## 复制表

在目录中**复制**表，然后**粘贴**到另一个 Cassandra 或 ScyllaDB 连接（或本连接）的键空间中。表会连同其列、分区键和聚簇键及其顺序、注释、二级索引以及所用的用户定义类型一起到达；窗口会显示每条语句，在点击**复制**之前不会运行任何内容。

- 先创建目标键空间中缺少的类型，然后是表，再是表的行，最后才是索引。
- 计数器表不会被复制：计数器无法通过 `INSERT` 写入。物化视图不会被复制；读取被复制表的视图会在窗口中列出。
- 如果复制失败或被停止，它创建的表会被删除。
- 读取期间不会冻结这些表：期间写入的行可能到达，也可能不到达。

粘贴到其他类型连接中的行，按任何表的行的方式处理。

## 备份

Cassandra 和 ScyllaDB 暂不提供备份。

## 仪表板

Cassandra 连接可以向仪表板报告数据。布局为 **Cassandra 节点**：客户端，以及节点估算的连接键空间的大小和分区数；在 Cassandra 上还有每秒的请求、读取、写入和压缩次数以及等待中的工作。ScyllaDB 把这些计数器保存在自己的监控端点中，此连接不读取。

## 你自己的服务器

**新建连接**在 Cassandra 卡片上提供**在此启动 Apache Cassandra**，在 ScyllaDB 卡片上提供**在此启动 ScyllaDB**：在本机启动一个节点，并保存为以超级用户 `cassandra` 和为其生成的密码登录的连接。Cassandra 节点需要一两分钟才会响应，并在响应后自行设置密码。如果带示例数据，它会打开 `demo_lab`——组织及其人员、项目及其任务、三十天内的两万次页面浏览，以及按页面统计浏览量的计数器表——每个界面都有可看的内容：静态列、用户定义类型、集合、时长、二级索引、物化视图，以及从新到旧的聚簇顺序。
