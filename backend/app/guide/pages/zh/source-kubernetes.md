# Kubernetes

通过 API 服务器访问的 Kubernetes 集群：任何集群都可以——你自己的、k3s、kind，
或由云平台运行的集群。你可以以集群自身的表格查看它的命名空间和它提供的每种对象
（包括自定义对象）、集群对每个对象的描述、Pod 的日志以及集群的报告。连接的一般
用法见[连接](connections.md)页面。

## 你可以看到的内容

- 命名空间及其中的每种对象，按 kubectl 用户熟悉的方式分组
- 不属于命名空间的类型：节点、卷、各种类等
- 自定义资源，与内置类型一样被发现
- 以 `kubectl get` 的表格显示某类型的对象，可排序和筛选
- 对象的概览：状态、元数据、状况及其内容
- 以 YAML 或 JSON 树查看对象
- 对象的事件，以及工作负载或服务选中的 Pod
- 容器的日志，最新的在前
- 集群：版本、节点、各阶段的 Pod、事件和 API 资源

## 你可以更改的内容

- 扩缩 Deployment、StatefulSet 和 ReplicaSet
- 像 rollout restart 一样重启 Deployment、StatefulSet 和 DaemonSet
- 封锁、解除封锁和排空节点，排空以作业方式运行
- 暂停、恢复和立即运行 CronJob
- 删除任何对象，先由集群自身试运行
- 在对象打开处编辑其 YAML，以及从 YAML 新建对象

## 连接

**登录方式** 决定 DataPlayer 如何登录集群：

- **kubeconfig**：粘贴文件，或用字段旁的按钮从磁盘读取。证书和私钥必须包含在
  文件中，而不是引用其他文件；`kubectl config view --minify --flatten` 可生成
  这样的文件。**上下文** 指定要使用的上下文；留空则使用文件的当前上下文。
- **令牌**：**API 服务器** 的 `https://` 地址、它的 **CA 证书** 以及 bearer
  **令牌**，例如服务账号的令牌。
- **客户端证书**：API 服务器、它的 CA，以及集群接受的 **客户端证书** 和
  **客户端私钥**。私钥不能加密。

只有当服务器证书由公共机构签发时，才可以将 **CA 证书** 留空。将 **命名空间**
留空可查看你有权列出的所有命名空间；如果你的账号只能在某个命名空间中工作，请填写
其名称。

有些 kubeconfig 会被拒绝，并说明各自的原因：

- 通过运行程序登录的——`gke-gcloud-auth-plugin`、`aws`、`kubelogin` 等：
  DataPlayer 不在其服务器上运行任何程序；
- 引用文件而不包含其数据的；
- 关闭了服务器证书校验的；
- 使用用户名和密码登录的，Kubernetes 已移除这种方式。

只有当 API 服务器只能从另一个网络访问时，才选择 **SSH 隧道**。集群必须运行
Kubernetes 1.27 或更高版本。

## 目录

- **集群** 包含集群的报告，见下文。
- **命名空间** 列出每个命名空间，最前面是 **所有命名空间**，它带
  **Namespace** 列显示所有命名空间中的各个类型。
- 在命名空间中，类型被分组为：**工作负载**、**网络**、**配置**、**存储** 和
  **其他**。“其他”包含集群提供的除常见类型外的所有类型，包括自定义资源，
  每个都标明其 API 组。
- **集群资源** 包含不属于命名空间的类型，分组方式相同，其中 **集群** 下是节点、
  命名空间和定义。
- 类型以表格打开，其列与 `kubectl get` 为该类型显示的列相同，并以 **Created**
  代替存在时长，以便排序。目录中每个对象的名称旁会显示其前几列，例如
  `1/1 · Running`。同一类型超过一万个时不再列出。

## 对象如何打开

- 点击对象可打开其概览：类型、命名空间、创建时间、所有者和状态，然后是该类型
  需要关注的内容——Pod 的节点、地址和容器及其镜像、状态和重启次数；Deployment
  的期望、就绪和已更新副本数；服务的类型、地址和端口；节点的版本和容量；卷声明的
  存储类和大小——然后是它的状况、标签和注解。
- 概览顶部可以在单独的标签页中以 **以 YAML 查看** 或 **以 JSON 显示** 打开对象。
  Kubernetes 用来记录谁改了什么的字段不会显示。
- 它的页面以表格形式在单独的标签页中打开：关于它的 **事件**；Deployment、
  StatefulSet、DaemonSet、ReplicaSet、Job 或服务选中的 **Pod**；以及 Pod 的
  **日志**，每个容器一页：时间和文本，最新的在前，最多一万行，每行截断为 16 KB。
- **Secret 的值从不显示。** 它的概览只列出键及其大小，它的 YAML 和 JSON 在每个值
  的位置显示大小。

## “集群”部分

- **概览**：版本、服务器、上下文、集群把你识别为谁、就绪节点、平台，以及命名空间
  数量和各阶段的 Pod 数量。
- **节点**：每个节点的状态、角色、版本、地址、操作系统、运行时、容量、可分配量和
  污点。
- **事件**：集群最近的记录，最新的在前。
- **API 资源**：集群提供的每种类型及其组、版本、作用域和动词。

## 被拒绝时

- API 服务器不可达、证书不受信任，或令牌、证书不被接受，都会让整个连接停止，
  每个界面都会说明原因。
- 集群自身的访问规则可能拒绝单个请求。此时会显示 **集群不允许此连接** 以及所请求
  的操作，例如 `list secrets`；集群的其余部分仍可读取。

## 更改

对象上方的菜单和其概览顶部的图标只提供集群允许你的账号执行的操作：集群访问规则会拒绝
的操作不会出现。扩缩、重启、封锁和暂停需要该连接的写权限；删除、排空和新建对象需要结构
权限。

- **扩缩容** 询问副本数（已填入当前值），并在执行前说明将发生的变化。
- **重启** 像 `kubectl rollout restart` 一样逐个替换工作负载的 Pod。
- **封锁** 和 **解除封锁** 禁止或允许新 Pod 调度到节点上。**排空** 会封锁节点，并在
  **活动** 中以作业方式逐个驱逐其 Pod；DaemonSet 的 Pod 和静态 Pod 保留，带有
  `emptyDir` 数据的 Pod 需要勾选“数据会丢失”的选项，中断预算最多等待你指定的秒数。
- **暂停**、**恢复** 和 **立即运行** 作用于 CronJob；立即运行会像
  `kubectl create job --from` 一样从其模板创建作业。
- **删除** 会先让集群试运行删除，并说明谁拥有该对象且会重新创建它；你可以选择它所拥有
  的对象如何处理。
- **以 YAML 查看** 会打开对象供编辑。只有在你打开后没有人修改过它时，保存才会提交；否则
  请重新读取后再编辑。其类型、名称和命名空间保持不变。Secret 不在此处编辑。
- **从 YAML 新建** 可在命名空间或类型上使用，接受一个或多个对象。集群先逐一试运行，表单
  显示将创建或修改的内容，或某个对象被拒绝的原因；随后按顺序应用。

## Kubernetes 在这里还没有的功能

- 容器内的终端、实时更新的日志
- 仪表板上的指标、搜索、将集群中的数据库作为连接打开
- 使用 Google Cloud 账号登录 Google Kubernetes Engine
- 按需显示 Secret 的值
