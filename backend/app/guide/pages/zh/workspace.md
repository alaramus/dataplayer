# 工作区

**数据** 空间用于打开连接并读取其内容。其他空间的说明见[DataPlayer 概览](overview.md)。

## 三列

- **连接**，左侧：你拥有的或别人共享给你的所有连接。点按一个连接会打开它的目录。参见[连接](connections.md)。
- **Catalogs**，中间：每个已打开连接的内容，逐级显示。顶部的筛选框按名称缩小当前层级；其搜索按钮在下层所有位置查找名称。**在旁复制目录** 会打开同一目录的第二个副本。
- **Work**，右侧：从目录打开的表、文件、查询、结构和图表，每个都在一个标签页中。为空时，会提示下一步该做什么。

拖动列之间的分隔线即可调整列宽。你离开时的布局，下次打开时仍会保留。

## 标签页

- 标签页像浏览器标签一样拖动：放到另一列的标签栏上会并入该列；放到某一列的内容区中，会把该列一分为二。标签页只能移到接受其类型的列中。
- **在目录中显示** 在目录中找到标签页对应的节点。
- **在窗口中打开** 把标签页拉出为浮动窗口，**作为标签页打开** 则把它放回标签页。
- **关闭其他标签页** 是列标签末尾的按钮，会关闭除当前显示之外的所有标签页。
- 刷新按钮旁的标记，在显示内容刚从数据源读取时显示 **实时**，显示的是缓存结果时则为时钟图标。将鼠标指向它，可看到结果有多久了。

布局的一部分可以收起：它会离开屏幕，并以按钮的形式保留在底部的 **放到一旁的区域** 中，点按即可恢复。

## 标签组

在 Data 中打开的标签页及列的布局，可以以一个名称保存。

- 右上角栏中的 **保存组** 保存当前打开的内容。
- 旁边的 **已保存的标签组** 列出已保存的标签组。打开某个组会替换当前打开的标签页，并先询问。
- **管理组** 可以重命名标签组、删除它，或用当前布局更新它。删除标签组不会关闭任何标签页。

## 浮动窗口

连接的设置、表单、提问以及拉出的标签页都在浮动窗口中打开，可以同时打开多个。DataPlayer 不会阻挡屏幕的其余部分。

- 窗口可通过标题栏移动，通过边缘调整大小，并有 **最小化**、**最大化** 和 **关闭窗口**。
- 含表单的窗口只能通过右上角的叉号关闭，因此按 Esc 不会丢失已输入的内容。提问窗口同样可以按 Esc 关闭。
- 最小化的窗口会在屏幕底部的 **打开的窗口** 中等待。

## 并排的两个连接

目录标题中的 **与另一个连接配对** 会把两个连接的目录放在同一窗口中，以便在它们之间移动内容：窗口会显示哪些内容可以从一方移到另一方，**交换两侧** 可以反转方向。**忘记此配对** 会关闭这一配对。

## 活动与通知

右下角的活动铃铛会打开 **活动**，分为三部分：

- **需要你处理**：等待你回应的事项——代理的提问、有人请求访问你的连接、停止响应的连接、失败的任务；
- **正在处理**：服务器为你执行的工作——复制、备份、流水线运行、启动服务、在文件中搜索。长时间的工作如果允许，可在此暂停或停止；
- **最近**：最近发生的事情。**全部清除** 会清空它。

简短的通知会以卡片形式出现在右下角，并进入 **最近**。**勿扰** 会停止弹出卡片；所有内容仍保存在 Activity 中。
