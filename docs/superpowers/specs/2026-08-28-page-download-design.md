# Скачивание видимой страницы и команды открытой таблицы

## Задача

Пользователь скачивает CSV не всего отношения, которое может быть огромным, а
ровно одной ограниченной страницы грида. Каждая такая выгрузка одновременно
остаётся в личном файловом пространстве пользователя, сгруппированной по
подключению. Команда структуры относится к уже открытой таблице и потому
переезжает из строки каталога в шапку грида.

## Контракт страницы

Запрос скачивания несёт тот же `node_id`, `limit`, `offset`, фильтры и
упорядоченную сортировку, что текущий `FetchRequest`, плюс заголовок вкладки и
имена видимых колонок в их экранном порядке. Ограничение `MAX_LIMIT` остаётся
общим с обычной выборкой: отдельного «без лимита» у выгрузки нет.

Сервер заново вызывает `SupportsFetch`. Поэтому механизм одинаков для
PostgreSQL, табличного файла и любого будущего источника, который уже умеет
отвечать строками и колонками. Отдельная способность `SupportsExport` не нужна:
она повторила бы существующую табличную границу.

Клиентские строки не принимаются. Иначе браузер мог бы сохранить произвольные
данные под видом выгрузки источника, а сервер потерял бы возможность проверить
состав колонок. Запрошенные видимые колонки сверяются со свежим `FetchResult`;
неизвестное или повторённое имя даёт 422.

## Файл

Один и тот же файл записывается в
`<user-home>/downloads/<connector-id>/<safe-title>-<UTC timestamp>.csv` и
возвращается браузеру как attachment. Имя не содержит клиентских сегментов
пути. Запись идёт во временный `.part` и атомарно переименовывается, чтобы
оборванная операция не выглядела готовой выгрузкой.

Кодировка — UTF-8 с BOM для практической совместимости с табличными
редакторами. Заголовок содержит видимые колонки в экранном порядке. SQL null is
written as an empty unquoted field and every other value is quoted, the
convention PostgreSQL's own `COPY ... CSV` reads back, so null stays
distinct from the empty string. The standard CSV writer handles quotes,
commas and newlines inside values.

Corrected during execution: this first specified `\N` for null. A cell
whose value is literally those two characters was then indistinguishable
from a null, which no round trip could recover.

## Интерфейс

Download и Show structure находятся в `GridHeader`. Download недоступен до
успешного ответа страницы или когда нет ни одной видимой колонки. Во время
записи повторное нажатие недоступно; успех и безопасная ошибка показываются
toast-сообщением.

Show structure открывает существующую structure-вкладку через workspace action.
Для читаемого, но не описываемого табличного источника команда не рисуется.
Признак `describable` поэтому путешествует с rows-панелью от каталожного узла,
не выводится из типа адаптера и не проверяется повторно по имени вида узла.

## Гонка свежести

Между показом страницы и скачиванием источник может измениться. CSV отражает
момент скачивания. Точное воспроизведение старых пикселей потребовало бы
source-owned snapshot/version token; пересылка уже показанных строк назад на
сервер таким токеном не является.
